# Frontend

The app will have the following pages

1. a teachers management page
    a. a teacher can be added or removed or modified
    b. i can assign a matter to a teacher, picking from the matter list
2. a class management page
    a. a class can be added or removed or modified
    b. matters can be attached to a class, removed from a class or modified ( for example to change the requirements)
    c. assigned matters should show requirements applied
    d. when a matter is assigned to a class, it should inherit the default requirements. However it must be possible to override them, adding new ones (from the list of available one) or disabling some.
3. a matters management page
    a. a matter can be added, removed, or modified
    b. matters has a number of teaching hours 
    c. matters has a list of default requirements
4. a scheduling management page
    a. i can start a new scheduling optimization, and see if it's done or not
    b. i can browse my schedulings
    c. i can visualize my schedulings
